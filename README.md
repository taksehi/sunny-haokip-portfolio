## ✨ Key Highlights & Interactive Features

### 1. 🖥️ Interactive 8-Bit Retro Microcomputer
- **3D Scroll Rig:** Grounded naturally on the meadow grass beside the notebook. Unfolds into center stage as the user scrolls.
- **CRT Shader & BIOS Boot Check:** Complete with CRT scanline curvature, power capacitor hum, floppy drive stepper head buzz, and system ready diagnostics.
- **Interactive OS Desktop:** 4 desktop program icons launching Dev Systems, Cinema Reel, Field Notes, and Frequency Radio with a retro taskbar.

### 2. ☀️ Continuous 24-Hour Solar & Atmospheric Simulation
- **Live Solar Angle Math:** Continuous real-time lighting calculation based on user local time or manual override.
- **Celestial Arcs:** Sun and moon follow natural parabolic trajectories behind the pixel-art natural tree canopy.
- **Dynamic City Skyline:** 1:1 pixel-registered building window lights and beacon glows that ignite automatically at dusk.
- **Easter Egg HUD Scrubber:** Top-right pill widget allowing visitors to scrub through 24 hours of golden sunsets, midnight moonlit indigo washes, and crisp midday skies.

### 3. 🔊 Tactile Web Audio FX Engine
- 100% synthesized in real time via the native Web Audio API (0 KB audio downloads).
- Mechanical keyboard clicks, camera shutter slaps, floppy seek buzz, and frequency radio chirps.

### 4. ⚡ Dual Showcase Worlds
- **Systems Architect [ Dev & AI ]:** Solo end-to-end builds (NERCORMP Government Deployment, OCR/RAG Pipelines, Agent Systems), live stack radar, and interactive project cards.
- **The Director [ Cinema & Film ]:** 4K video modals, interactive split-screen color grading wipe (LOG vs Rec.709), camera gear breakdown, and showreel playback.

### 5. 🎯 Recruiter Lens & ATS Dossier
- One-click recruiter mode with quick skill tags, education timeline, and printable ATS-friendly PDF/clean dossier export.

### 6. 🎮 Gamepad & Accessibility
- Full Gamepad navigation support for Smart TVs and controllers.
- Accessible fallbacks with `prefers-reduced-motion` compliance across all animation hooks.

## 🛠️ Tech Stack

- **Frontend:** React 18, Vite 6, Plain CSS Design System
- **Kinetic Motion:** Anime.js v4, View Transitions API
- **Audio:** Web Audio API (Oscillators, Biquad Filters, Gain Nodes)
- **Database & Serverless API:** Neon Serverless PostgreSQL (`@neondatabase/serverless`)
- **Icons & Typography:** Lucide React, Plus Jakarta Sans, EB Garamond, JetBrains Mono, Inter
- **Hosting & CI/CD:** Vercel Edge Network

## 🚀 Local Development

1. **Clone the repository:**
   ```bash
   git clone https://github.com/taksehi/sunny-haokip-portfolio.git
   cd sunny-haokip-portfolio
   ```

2. **Install dependencies:**
   ```bash
   npm install
   ```

3. **Start local development server:**
   ```bash
   npm run dev
   ```
   Open [http://localhost:5173](http://localhost:5173) in your browser.

4. **Build production bundle:**
   ```bash
   npm run build
   ```

5. **Preview production bundle locally:**
   ```bash
   npm run preview
   ```
